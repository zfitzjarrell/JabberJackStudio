# v0.6.0 - First public release

Initial GitHub-ready release of the Jabberin' Jack Custom Video Generator.

### Highlights
- Generates hardware-tested AMV files from custom audio.
- Traditional, Funny, Scary, and Angry factory styles imported locally from the owner's original media.
- PC preview generation.
- 180-degree pumpkin output rotation.
- 0-30 second Black, Idle Face, or Idle + Expressions end pause.
- Correct digital-silence padding.
- Factory filename selection for slots 1-10 and custom filenames for 11+.

### Required
- Windows
- FFmpeg
- Original Jabberin' Jack AMV media for local face import

Factory media and extracted artwork are intentionally not included.
