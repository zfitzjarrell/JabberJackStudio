# JabberJack Studio v0.7.0

Adds a second primary workflow: **Custom Video**. Import ordinary video, crop/fit it for the 208×176 projector, trim it, keep or mute audio, add an optional end pause, preview it, and create a pumpkin-ready AMV.

Talking Pumpkin remains available with the tested face/audio workflow.

Hardware access is still required. Some hardware revisions may require opening the pumpkin and soldering a USB connection to its internal board. Back up the original storage before modifying anything.
