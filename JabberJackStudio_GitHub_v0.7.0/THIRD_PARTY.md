# Third-party software and media

## FFmpeg
This project invokes FFmpeg but does not include an FFmpeg binary in the repository. FFmpeg has its own license terms. Users may install FFmpeg separately or place `ffmpeg.exe` in `app/tools/`.

## Jabberin' Jack factory media
Factory AMV files and artwork are **not included**. The import utility extracts face frames locally from original media supplied by the device owner. Those extracted files are ignored by Git and are not covered by this project's MIT license.
